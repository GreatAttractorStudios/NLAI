# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-XX

### Added
- Initial release of the Natural Language NPC (NLNPC) package
- Core systems for converting natural language descriptions to Behavior Trees
- Graphical editor window with tree generation and visualization
- Real-time behavior tree visualizer with node status indicators
- Intelligent feedback system for missing capabilities
- Assembly definitions for proper package structure
- Comprehensive example Actions and Senses in dedicated Samples folder
- Guard Patrol and Resource Gatherer example implementations
- Detailed documentation and behavior tree execution guide

### Changed
- Renamed from NLAI to NLNPC (Natural Language NPC)
- Updated all references and branding
- Improved package structure for Asset Store compliance
